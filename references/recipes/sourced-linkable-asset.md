# Sourced linkable asset

ID: `sourced-linkable-asset` | Version: `1.0.1` | Goal: `build-content`

Use this recipe for a reference, guide, comparison, dataset, calculator or template that helps a named reader. Modes: local, hosted, external. Required inputs: the site/context brief, reader task, candidate asset or existing page, source material and intended output destination.

## Capabilities and ownership

The agent can write a sourced draft without an AgentLinkOps account. Fetching sources and editing a website depend on the user's available tools. Hosted backlink research is optional and requires actual access. The user's site or content system owns the asset; local CRM storage is optional. For page work, preserve the site's rendering and routing conventions and inspect nearby pages before editing. Use the customer's chosen source, editorial and review process. Selecting this recipe does not install the optional content skills or require that writing method; see [optional writing and review guidance](command-notes.md#optional-writing-and-review-guidance) if the customer chooses the packaged passes.

## Steps and checkpoints

1. Read the site's applicable content instructions and inspect existing pages for the same reader task. Define the useful addition before creating another URL. Identify the customer's required writing and review steps. If a required review resource is unavailable, identify it before marking the asset reviewed.
2. Write with the customer's chosen source process. Preserve source title, publisher, publication date when available, URL and the evidence supporting each factual claim. Mark original calculations and assumptions. Do not manufacture experience or results.
3. Use the customer's editorial and final-text review process. Save the actual checks, reviewer or tool used, revision and unresolved findings. A selected packaged pass keeps its own rules; an unrun pass is not a completed review.
4. Check links for the chosen format. For owned pages, verify destinations and inbound discovery at release. A document or email handoff needs relevant links without webpage quotas. Use the site's image workflow when the asset calls for images.
5. Complete the customer's required release review. Checkpoint the draft revision, intended URL, source records, review receipts and unresolved findings. Read back the artifact from its chosen destination.

## Recovery and completion

Missing sources leave claims unverified; remove or qualify them before review. Missing review tools leave the corresponding pass incomplete. Preserve an existing page and customer edits when resuming. A draft, green build or copied command does not prove publication. If release is authorized separately, verify the actual public content after release and attach that receipt.

Complete this recipe with a reviewed draft and explicit publication state, or an unfinished draft with the precise remaining check. A campaign continuation uses the customer's chosen process. If the customer chooses the packaged [campaign handoff](qualified-campaign-handoff.md), select it separately with `agentlinkops agent setup --recipe qualified-campaign-handoff` before reading it. Carry an honest asset state into either process; a pitch must not describe an unpublished asset as live.
